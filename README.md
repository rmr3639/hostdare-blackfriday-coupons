## 四、黑五购买避坑指南

讲几条容易翻车的细节。

### 1. 优惠码必须配合"年付及以上"周期

HostDare所有黑五优惠码都只在 annual / biennial / triennial（年付、两年付、三年付）周期生效。月付、季付、半年付都不能用码——这一点官网写得清清楚楚。如果你只想月付试试，那就别指望优惠码了，乖乖付原价。

### 2. 双倍内存/流量福利要主动工单申请

这条是新手最容易漏掉的。官方原文是"If you order any ASSD/SSD/CSSD/CAMD vps for annual payment, we will give you DOUBLE RAM AND BANDWIDTH, just Reply this thread with your invoice number."——下单后必须**主动开个工单附上订单号**，福利才会真正加上。光下单不开工单，你的SSD0就只有768MB内存而不是1.5GB。

### 3. CSSD/CAMD/CKVM的100Mbps端口升级也要工单

CN2 GIA系列默认端口是30~100Mbps按套餐递增，但黑五期间官方承诺**免费升级到100Mbps**，同样需要工单申请。别傻乎乎就用默认带宽了。

### 4. 优惠码只能用3个续费周期

官方原话"All discounts coupons are valid for 3 payment term only"——意思是循环折扣只在前3次续费生效，第4次起恢复原价。所以如果你打算长期用，年付3年其实是最划算的，能锁定3年折扣价。

### 5. 退款政策要记牢

HostDare的VPS有3天退款政策，但有条件：使用超过20%月流量就拒退，退款还要扣0.5~1美元手续费。所以下单后第一时间测速测路由，发现问题立刻申请退，别拖。

### 6. Windows系统要自己带授权

HostDare不卖Windows授权。CSSD2/CSSD3以上、ASSD2以上、CKVM3以上、HDD3以上、JSSD2以上、BGSSD2以上才支持装Windows，但license得你自己搞定。
